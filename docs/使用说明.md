## 安装与更新

影择支持 Apple Silicon Mac，系统要求 macOS 14 或更高版本。

1. 打开 [GitHub Releases](https://github.com/BBin17/yingze/releases/latest)，下载以 `arm64.dmg` 结尾的安装包。
2. 双击打开 DMG，把“影择”拖入“应用程序”。
3. 从“应用程序”打开影择。更新时也使用同一个位置，并在系统提示时选择替换。

支持应用内更新的版本会在启动时检查 GitHub。有新版时会显示更新说明，也可以在菜单栏选择 **影择 → 检查更新…**。点击 **下载更新**，等待 SHA‑256 校验完成后点击 **打开安装包**。退出影择，将新版拖入「应用程序」，选择替换后重新打开。应用内下载不可用时，可以打开 GitHub 发布页获取安装包。

当前安装包尚未经过 Apple Developer 签名与公证，macOS 可能在首次打开时显示安全提示。请先确认下载来源；如需处理提示，可参考 Apple 的[安全打开 Mac App 说明](https://support.apple.com/zh-cn/102445)。不要从未知来源下载安装包。

## 创建和打开项目

1. 在首页点击 **打开照片文件夹**，选择包含照片的文件夹。
2. 在“新建项目”窗口确认文件夹，输入项目名称，点击 **创建并打开**。
3. 等待扫描完成。之后可从首页进入已有项目；来源文件夹需要保持可访问。
4. 来源文件夹增加或改变照片后，可在项目中点击刷新按钮重新扫描；现有精选、废片、星级和颜色记录会尽量保留。

影择会按文件名整理照片组。例如 `DSC00123.JPG`、`DSC00123.ARW` 和 `DSC00123.XMP` 可作为同一照片组处理。单独的 RAW 或成片也可以浏览、选片和导出。支持 JPG/JPEG、HEIC/HEIF 和多种相机 RAW 格式；具体 RAW 的解码效果取决于 macOS 支持情况。

## 浏览和挑选照片

项目中可使用顶部视图按钮或快捷键切换：

- **网格**：一次查看多张缩略图。
- **单张**：专注查看当前照片。
- **双图 / 多图**：并排比较照片。

可将值得保留的照片标记为**精选**，将不需要的照片放入**废片**。左侧“选片”显示未淘汰的照片，“废片”用于查看被淘汰的照片；选中废片后可以恢复。需要撤回上一步评分、颜色或去留操作时，可使用撤销。

> 废片是影择中的分类，放入废片不会删除或移动来源文件。精选、废片和评分记录保存在本地项目中。

## 评分、颜色与筛选

选中照片后，可设置 0–5 星以及红、黄、绿、蓝、紫颜色标签。评分和颜色可以配合筛选使用，例如先标记值得进一步处理的照片，再筛选检查。

导出时，影择会为导出的照片组写入包含星级与颜色标签的 XMP；如果原有 XMP 存在，会以其内容为基础生成导出用 XMP。不同软件对标签的识别方式可能不同，建议在常用修图软件中先用少量照片验证。

## 导出照片

1. 点击项目界面中的 **导出**。
2. 选择合适的范围：**最终精选**、**全部未淘汰**、**当前筛选结果**或**当前临时多选**。各范围旁会显示照片组数量。
3. 确认文件夹名称，选择本机文件夹，或先在 Finder 中连接 NAS，再选择已挂载的 NAS 目录。
4. 如需按来源文件夹中的结构保存，勾选 **保留来源子目录**。不同子目录中同名的照片可以分别导出，关联的 RAW、成片和 XMP 会放在一起。
5. 核对预计复制数量和大小，点击 **开始导出**。导出未完成时，结果会列出失败文件及原因。处理问题或重新连接 NAS 后，点击 **继续导出**。

重新打开影择后，可在同一项目的导出窗口中选择 **继续上次导出**。影择会沿用上次的照片范围、目标位置和目录设置，复用目标位置仍能通过校验的暂存文件。

影择会复制所选照片组及其关联文件到新目录，并进行 SHA-256 校验，不会移动来源文件。目标文件夹已存在或存在文件名冲突时，程序可能阻止导出；请检查目标位置并选择合适的新名称。NAS 导出时请确保连接稳定且空间充足。

## 项目记录与备份

项目索引和选片记录保存在当前 Mac 用户目录下的 `~/Library/Application Support/CameraCull/`。它们与照片源文件分别保存；如需迁移或备份项目，请保留该目录并另外备份源照片。

影择会为项目记录保留备份。如果读取记录失败，程序可能从备份恢复或暂停写入以保护原记录；请保留整个 `CameraCull` 文件夹，检查恢复提示及选片结果。备份不一定包含最近一次修改。

## 常见问题

### 为什么找不到照片或项目打不开？

检查照片来源文件夹是否还在原位置，移动硬盘或 NAS 是否已连接，以及影择是否有访问该文件夹的权限。重新连接后再尝试打开项目或刷新。

### 为什么 RAW 看不到预览？

不同相机 RAW 的解码支持由 macOS 和文件本身影响。先确认文件可在系统“预览”或“照片”中打开，必要时更新 macOS；也可保留配对的 JPG 或 HEIC 供浏览。

### 为什么不能导出？

确认选择的范围不是空的、目的地有足够空间和写入权限，并检查是否存在同名目标目录或照片配对冲突。导出到 NAS 时还需确认连接仍然可用。查看软件显示的错误信息，处理后重试。

### 废片会被删除吗？

不会。放入废片只改变影择内的分类，源照片保持原位；可以进入废片区恢复。

### 评分和颜色会直接修改原始照片吗？

不会。选片记录保存在本机项目中，导出时生成用于导出照片的 XMP，来源文件保持不动。

如需反馈问题，请前往 [GitHub Issues](https://github.com/BBin17/yingze/issues)，附上影择版本、macOS 版本、操作步骤和错误提示。分享日志或样片前请先检查个人信息。
